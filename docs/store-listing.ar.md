## الوصف

```text
يخفّض nomusic الموسيقى الخلفية ويبقي الأصوات: الكلام والغناء. متوافق مع YouTube™. صُنع لمن يريد تجنّب الموسيقى لأسباب دينية أو شخصية، ولمن يفضّل الأصوات مع موسيقى خلفية أقل.

كيف يعمل
• يعمل فصل الصوت على جهازك باستخدام نموذج مفتوح المصدر مضمّن في الإضافة. لا حاجة إلى حساب ولا إلى خدمة خلفية.
• بعد اختيار «تشغيل nomusic» تكون الإزالة التلقائية مفعّلة. أوقفها من شريط الأدوات إذا أردت تشغيلها لكل فيديو على حدة.
• قد يتوقف الفيديو لحظةً في البداية أو بعد التقديم بينما يُجهَّز الصوت. يقول الزر «جارٍ إزالة الموسيقى…» أثناء ذلك.
• انقر «أُزيلت الموسيقى» في المشغّل لسماع الصوت الأصلي، ثم انقر «أزِل الموسيقى» لإعادة الإزالة. قبل الاختيار الأول يقول الزر «إعداد nomusic».

أدوات التشغيل
مستوى الصوت وكتمه والتقديم وملء الشاشة وتغيير السرعة مدعومة. يعمل nomusic أيضًا مع المقاطع القصيرة والبث المباشر والمشغّلات المضمّنة على الحاسوب، عندما تكون مدعومة.

الخصوصية
يقرأ nomusic الصوت الذي حمّله مشغّل الموقع أصلًا ويعالجه في ذاكرة المتصفح لإزالة الموسيقى فقط. لا يُرفَع الصوت ولا يُشارَك ولا يُحفَظ ملفًا. لا يوفّر تنزيل وسائط ولا تسجيلًا ولا تصدير صوت. لا يتلقى المطوّر الصوت ولا سجل التصفح ولا تحليلات الاستخدام. يُحفَظ إعداد الإزالة التلقائية، وما إذا كنت قد شغّلت nomusic، في تخزين إضافات Chrome وقد يتزامنان بين أجهزتك عبر Chrome Sync.

حدود ينبغي معرفتها
• قد تبقى بعض الموسيقى، خصوصًا الموسيقى الهادئة تحت الكلام. قد تبدو الأصوات أقل وضوحًا في طبقاتها العالية. هذا ليس ضمانًا لتشغيل خالٍ من الموسيقى.
• تعمل المعالجة على خيط معالج واحد وتستخدم نحو 450–500 ميغابايت من الذاكرة، ويختلف الأداء باختلاف الجهاز والفيديو.
• لا يمكن معالجة الفيديو المحمي ضد النسخ. عند فشل الإزالة يقول الزر «لم تُزَل الموسيقى». يتوقف الفيديو ويبقى الصوت الأصلي صامتًا حتى تختار «حاول مرة أخرى» أو «شغّل مع الموسيقى». بعض حالات الفشل تطلب «أعد تحميل الصفحة» بدلًا من ذلك. إذا كان المتصفح ينتظر نقرة قبل تشغيل الصوت، يقول الزر «انقر لبدء الصوت».
• قد يتوقف البث المباشر مرارًا عند حافته المباشرة، والتشغيل متأخرًا عنها قليلًا قد يساعد.
• تدعم الإضافة مشغّلات الموقع على الحاسوب، لا متصفحات الهاتف ولا خدمات فيديو أخرى.

مجانية ومفتوحة المصدر. النص البرمجي والمساعدة: https://github.com/IbraheemTuffaha/nomusic
```

## ألفاظ الواجهة

These are the button strings the description uses. The extension UI must use
the same Arabic, including the ellipsis character … .

| English | Arabic |
| --- | --- |
| Turn on nomusic | تشغيل nomusic |
| Set up nomusic | إعداد nomusic |
| Remove music | أزِل الموسيقى |
| Removing music… | جارٍ إزالة الموسيقى… |
| Music removed | أُزيلت الموسيقى |
| Click to start the sound | انقر لبدء الصوت |
| Music not removed | لم تُزَل الموسيقى |
| Try again | حاول مرة أخرى |
| Reload page | أعد تحميل الصفحة |
| Play with music | شغّل مع الموسيقى |

«شغّل مع الموسيقى» means the video's music will play. Do not soften it to
"original". «أزِل الموسيقى» is the imperative. «أُزيلت الموسيقى» is the state
after removal. «انقر لبدء الصوت» means the video's sound, not the speaking
voice. The speaking voice in the description is «الأصوات: الكلام والغناء».
Instruments, where the UI names them, are «آلات موسيقية».
